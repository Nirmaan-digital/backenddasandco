DAS & CO BACKEND — HOSTINGER DEPLOYMENT

This archive contains backend files at the ZIP ROOT (package.json is at the root).

1. Upload this ZIP to the Hostinger Node.js application for api.dasandco.online.
2. Install dependencies with: npm install
3. Start command: npm start
4. Required environment variables:
   DB_HOST=...
   DB_PORT=3306
   DB_NAME=...
   DB_USER=...
   DB_PASSWORD=...
   JWT_SECRET=...
   JWT_EXPIRES_IN=...
5. Restart the Node.js application after deployment.

The backend automatically checks/creates missing client/order/settings columns used by the application.
